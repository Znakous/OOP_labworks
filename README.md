# Objected-oriented programming labworks
Implemented in C#
## Aim
Get aquanted with all GOF-patterns and clean architecture principles

Simple train movement simulation, covers just basic object-oriented, SOLID and GRASP principles

## Labwork 2
Messaging system simulation: covers structural patterns and mocking in tests using NSubstitude

## Labwork 3
Heartstone-like game simulation: covers creational patterns in combinations with structural

## Labwork 4
File system console app: covers all GOF-patterns

## Labwork 5
Bank system simulation: covers muli-layer architecture (onion preffered), introduces dependency injection
